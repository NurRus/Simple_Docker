# Simple Docker

Этот проект охватывает множество аспектов работы с Docker, Nginx и безопасностью контейнеров. Проект включает в себя создание и настройку Docker-контейнеров для веб-сервера на базе Nginx, разработку мини-сервера на C и FastCGI, а также использование Docker Compose для управления несколькими контейнерами. Проект также включает проверку безопасности контейнеров с помощью Dockle.

### Часть 1: Готовый Docker

 - Работа с официальным Docker-образом Nginx.
 - Выполнение базовых операций с Docker: pull, run, stop, restart.
 - Проверка и инспектирование контейнеров.
 - Настройка маппинга портов и проверка доступности веб-страницы.

### Часть 2: Операции с контейнером

 - Настройка конфигурационного файла Nginx внутри контейнера.
 - Экспорт и импорт контейнеров.
 - Проверка работы контейнера после импорта.

### Часть 3: Мини веб-сервер

 - Разработка мини-сервера на C и FastCGI.
 - Настройка Nginx для проксирования запросов на мини-сервер.
 - Проверка работы мини-сервера через браузер.

### Часть 4: Свой Docker

 - Создание Docker-образа для мини-сервера и Nginx.
 - Настройка маппинга портов и конфигурационных файлов.
 - Проверка работы контейнера и обновление конфигурации Nginx.

### Часть 5: Dockle

 - Проверка безопасности Docker-образа с помощью Dockle.
 - Исправление ошибок и предупреждений в Docker-образе.

### Часть 6: Базовый Docker Compose

 - Создание файла docker-compose.yml для управления несколькими контейнерами.
 - Настройка проксирования запросов между контейнерами.
 - Проверка работы контейнеров через браузер.
